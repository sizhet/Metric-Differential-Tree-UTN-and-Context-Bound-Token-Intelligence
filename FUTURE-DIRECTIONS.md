---

# 1. Purpose

The v1.0.0 release establishes the conceptual and algorithmic foundation of MDT-UTN-CBT.

It defines:

```text
Context
   ↓
GenericContainerStarmap
   ↓
Metric-Differential Tree
   ↓
Universal Typing & Naming
   ↓
Context-Bound Token
   ↓
Baseline-Preserved Context Injection
   ↓
Context Address
   ↓
Search · Cache · Delta · CCC · Brain Units
````

The next research stage should not immediately expand the framework in every possible direction.

The preferred strategy is:

> **Validate the smallest useful mechanisms first, then progressively turn validated mechanisms into runtime structure.**

The future program therefore follows:

```text
Validate
   ↓
Instrument
   ↓
Runtime
   ↓
Fold Experience
   ↓
Grow Structure
   ↓
Compose Intelligence
```

---

# 2. v1.0.0 Should Remain Algorithm-First

The current release should remain deliberately lightweight.

Its primary contribution is not an implementation package.

It is a structural argument:

```text
Context
→ Structural Identity
→ Context-Bound Encoding
→ Measurable Context Gain
→ Context Address
→ Reusable Intelligence
```

The v1.0.0 repository should therefore avoid being diluted by:

```text
large runtime frameworks
premature Java class hierarchies
tokenizer modification
model-weight modification
large synthetic benchmarks
production infrastructure
```

Those belong to later releases.

The immediate goal is to test whether the core structural mechanisms justify deeper engineering investment.
